Getting a live link from Google Sheets

  1. In your sheet, choose File → Share → Publish to web.
  2. Pick the tab you want, set the format to Comma-separated values (.csv), then select Publish.
  3. Copy the link, paste it above, and select Refresh data.
  4. A normal sheet link also works if sharing is set to "Anyone with the link can view". Any other public CSV URL works if its host allows cross-origin requests; otherwise use Upload CSV.
